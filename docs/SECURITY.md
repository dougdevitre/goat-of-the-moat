# Security policy

This is a public, non-production research prototype. Do not commit confidential evidence, customer data, personal information, private judge deliberations, credentials, or API keys.

Before accepting real evidence, implement authentication, authorization, encrypted storage, access logging, retention policies, upload scanning, and independent security review. GitHub issues are public in this repository; do not include confidential nominee information in issues.

No production hosting, database service, or external data integration is configured.
