# Calibration handbook — provisional v0.1

This release contains 100 calibration records and 600 universal score-anchor applications. **These are not 600 independently validated numerical thresholds.** The anchors are currently qualitative and require metric-specific calibration and empirical peer benchmarking before certification.

## Score interpretation

0 requires verified absence; missing evidence must remain unscored. Ratings 1–5 reflect increasing demonstrated defensibility and independent corroboration. Confidence A/B/C/U is a separate evidence attribute and must not be confused with the 0–5 rating.

## Peer group safeguards

Established institutions, enterprise platforms, AI-native providers, public/nonprofit infrastructure, and specialists must be assessed against suitable peers and maturity-adjusted baselines. Financial metrics for nonprofits should use sustainability and mission-adjusted measures rather than mechanically applying profit metrics.

## Required improvements

- Define numerical 0–5 thresholds per question wherever possible.
- Publish dated peer sample definitions, distributions, and source provenance.
- Specify measurement units, time windows, missing-data treatment, and applicability review.
- Require evidence-verification signoff and independent calibration before official rankings.

## Data handling

No confidential evidence is stored in this public repository. Evidence validation checks metadata completeness only and does not independently verify claims.
