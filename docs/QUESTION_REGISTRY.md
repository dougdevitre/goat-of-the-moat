# Question registry v0.1

The 100-question registry is stored in `data/questions.v0.1.json`.

**Provenance limitation:** The full signed founding charter was not available for verbatim import. These are **draft paraphrases based on the prior charter summary**, not certified canonical question text. The evidence requirement is currently specified per dimension and repeated for questions in that dimension. This is not yet sufficient for production evidence verification.

## Required before certification

1. Reconcile all 100 prompts against the original signed charter, preserving exact wording and IDs.
2. Specify question-specific measurable indicators, numerator/denominator, units, time window, peer group, and data sources.
3. Approve 0–5 calibration anchors and exception rules.
4. Document applicability decisions, evidence quality, and judge reconciliation.
5. Freeze a signed methodology version and rerun the complete test suite.

## Current automated checks

Question uniqueness, completeness, dimensions, 1,000-point totals, scoring ranges, and draft labeling.
